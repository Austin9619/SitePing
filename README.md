# SitePing
This is a console-based HTTP learning project that checks whether a website is online or offline by making an HTTP request and waiting for the response.

## Features
- Accepts a website URL as input
- Attempts an HTTP request to the site
- Determines whether the site is:
  - **Online** (reachable)
  - **Offline** (unreachable)
- Outputs a **simple, readable status** instead of raw HTTP data

---

## Why This Project Exists
This project was created as a **learning exercise** to help me study HTTP fundamentals in C#.  
Focus areas include:
- Understanding HTTP request/response flow
- Handling invalid or unreachable URLs
- Learning how network failures behave
- Writing clean, readable console output

---

## What This Project Is Not
- A full website monitoring tool  
- A production-ready uptime checker  
- A replacement for professional monitoring services
